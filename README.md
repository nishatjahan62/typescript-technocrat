# TypeScript Technocrat

A parent repository organizing my TypeScript learning journey across two main areas, managed as Git submodules.

## Structure

- [`typescript-types`](https://github.com/nishatjahan62/typescript-types) — Basic and advanced TypeScript types
- `typescript-oop` — Object-Oriented Programming in TypeScript (in progress)

## Usage

Clone with submodules:

\`\`\`bash
git clone --recurse-submodules https://github.com/nishatjahan62/typescript-technocrat.git
\`\`\`
